# Writing and styling

Everything here is free and works on any page in Projects.

## Move, colour and change a block

Hover a block and a grip appears beside it.

- **Drag the grip** to move the block. Drop it on the left or right edge of another
  block and the two sit **side by side** in columns.
- **Click the grip** for the block menu: **Turn into** (text, headings, lists, checklist,
  quote), **Color**, **Duplicate**, **Move up** and **Move down**, **Copy link to section**
  (on headings) and **Delete**.

Keyboard: `Mod + Shift + D` duplicates the block, `Alt + Shift + ↑ / ↓` moves it,
`Mod + K` links the selected text, `Mod + Alt + T` opens or closes every toggle. `Mod + /`
shows the full list. (`Mod` is Ctrl, or Cmd on a Mac.)

## Page style

The **T** button at the top of a page opens **Page style** for that page only:

- **Font:** Default, Serif or Mono.
- **Small text:** smaller body text.
- **Full width:** use the whole width instead of a reading column.

The page list starts closed in a narrow window so the page has the room; the button at
the top opens it.

## On this page

Once a page has two or more headings, **On this page** appears at the top. It lists the
headings, indented by level; choose one to jump to it. For a list inside the page itself,
type `/toc` for a **Table of contents** block. It follows the page as you edit.

## Toggle headings

Type `/toggle heading` for a heading that folds what is under it (level 1, 2 or 3). A
toggle stays open or closed the way you left it. Toggle headings are part of **On this
page** and of the table of contents.

## Tables

Select a table for its toolbar: add or delete rows and columns, **Header row**, **Header
col**, **Merge** (drag across cells to select them, then merge) and **Split**, cell
colour, and **Fit width**, which puts a table you resized by hand back to the width of
the page.

## Columns

Type `/columns` or drag one block beside another. Drag the gap between two columns to
change how the width is shared; the other columns do not move. On a narrow screen the
columns stack.

## Equations

Type `$$x^2$$` and the text between the dollar signs becomes an inline equation. Click an
equation to edit it. `/math` inserts a block equation.

## Dates

Type `@` and then `today`, `tomorrow` or `yesterday`. The date is the day it was where
you are (your account's time zone) and stays that day.

## Callouts

A callout's icon can be any of 40 symbols, chosen from its menu.

## Page icons

Besides an emoji, a page's icon can be a **picture you upload** (PNG, JPEG, WebP or GIF,
up to 2 MB). Choosing an emoji replaces the picture; **Remove icon** removes both.

## Embeds

Type `/embed` and paste a link to a **YouTube, Vimeo, Loom, Spotify, SoundCloud, Figma,
CodePen, Miro** or **OpenStreetMap** page. It shows inside the page, with an **Open on**
link beneath it. Other links are refused: Xenith only frames those providers, and it
builds the frame's address itself from the link, never from the text you pasted. For any
other site, use a **Bookmark**.
