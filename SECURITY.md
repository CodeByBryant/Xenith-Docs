# Security Policy

This repository contains the public documentation for Xenith. It does not
contain application secrets or user data.

## Reporting a vulnerability

If you discover a security issue in Xenith — whether in this site or the main
product — **please do not open a public issue**. Instead, report it privately:

- Email **security@xenith.life**, or
- See the responsible disclosure details at
  [xenith.life/security](https://xenith.life/security).

We appreciate responsible disclosure and will respond as quickly as we can.
